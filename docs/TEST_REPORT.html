R-01MediumTexture model misses digitally simulated prints / recapturesAS-15 (expected failure): the MiniFAS model, trained on physical attacks, passed simulated halftone prints and low-resolution recaptures as real. Mitigation: kiosk check-ins also need the random head-movement challenge, which planar media cannot perform (LV-04, LV-05, LV-13). CCTV sightings need natural movement too, or go to review.
